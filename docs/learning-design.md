# 教学设计 · Learning design

## 设计原则

1. **先听、后看、再读**。幼儿识字顺序是「音 → 形 → 义」。题型按熟练度递进，避免一上来就要求读字。
2. **错了也不惩罚**。答错不扣分、不计时，只降一级熟练度并给出提示；连续答错两次会高亮正确答案。
3. **每局短小**。一局 8 题（青蛙、骑车）或 5–8 个字（迷宫），3–5 分钟内结束，适合幼儿注意力。
4. **即时反馈**。答对立即朗读「字 + 组词」（如「火，火车」）并显示拼音，巩固音形义联系。

## 自适应题型（小青蛙过河 / 骑车闯关）

每个字有熟练度 `0–4`，保存在 `localStorage`：

| 熟练度 | 题型 | 说明 |
|---|---|---|
| 0 | 看图 + 听音找字 `picSound` | 有图片和声音双重提示 |
| 1 | 听音找字 `sound` / 看字选图 `read` 各半 | 去掉图片提示 |
| ≥2 | 看字选图 `read`（65%）/ 听音找字 `sound` | 真正的「读」；听音题混入形近字 |

- 第一次就答对：熟练度 +1，得一颗星
- 本题第一次答错：熟练度 −1
- 无中文语音时，听音题自动替换为看图题 `pic`

出题队列：取熟练度最低的 6 个字 + 2 个随机复习字，打乱后保证相邻不重复。

## 形近字

熟练度 ≥2 的听音题会混入一个形近字干扰项，例如：

```
人 → 入 八      日 → 目 白 田      木 → 本 禾
大 → 太 天      上 → 土 止          左 → 右 在
```

完整列表见各游戏源码中的 `LOOK` 常量。

## 扩展字库

字库写在每个游戏 `index.html` 的 `<script>` 中：

- 小青蛙过河 / 骑车闯关：`DECK_DATA`，每项为 `[汉字, 拼音, emoji, 组词]`
- 汉字迷宫：`DECKS`，每项为 `{ c, p, e, emo }`（字、拼音、英文、emoji）
- 狐狸指南针：`D`（方向）、`FACT`（小知识）、`ITEMS`（小动物 / 物品）

新增一组字示例（小青蛙过河）：

```js
{ id:'home', name:'我的家', icon:'🏠', items:[
  ['家','jiā','🏠','回家'], ['门','mén','🚪','开门'], ['床','chuáng','🛏️','起床'] ]},
```

注意事项：

- 每组至少 3 个字（每题 3 个选项）
- 同一组内 emoji 不要重复，否则看字选图题会出现两个相同图片
- 拼音使用带声调的字母（`ā á ǎ à`），不要用数字标调
- 修改 `DECK_DATA` 后两款游戏如需保持一致，请同步修改
